## 🧬 FILE 002 — SUBJECT OVERVIEW

**Mad Scientist** is a chaotic, text-based Python experiment simulator where you combine completely questionable ingredients and discover what happens.

```mermaid
flowchart LR
    A[🦇 Bat Wings] --> M{⚗️ MIX}
    B[🧠 Brains] --> M
    C[🧀 Cheese] --> M
    D[🧊 Liquid Nitrogen] --> M
    E[🌶️ Hot Sauce] --> M
    M --> R1[🦇🧠 Psychic Bat]
    M --> R2[🧀🧀 Genius Cheese]
    M --> R3[🔥 Fire Bat]
    M --> R4[🌋 Lava Cheese]
    M --> R5[💥 Thermodynamic Disaster]
    style M fill:#6A3FD9,color:#fff
    style R5 fill:#2CB1BC,color:#000
```

Some combinations might create:

🦇🧠 **A Psychic Bat**
🧀 **Genius Cheese**
🔥 **A Fire Bat**
🌋 **Lava Cheese**
💥 **A Thermodynamic Disaster**
