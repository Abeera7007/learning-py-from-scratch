# learning-py-from-scratch
# 🐍 Learning Python From Scratch

### From “Game Over” to "SyntaxError "

Welcome to my **Python playground**.

This repo is where I'm going to build random, fun, slightly chaotic, and increasingly difficult Python projects — starting with the absolute basics and gradually pushing my logic further.

No copy-paste mastery.
No "AI wrote it, I just ran it."
No skipping straight to frameworks.

Just **Python, logic, curiosity, and a lot of debugging.**

---

##  What's the Point?

I'm using this repository to document my **logical growth in Python**.

The goal isn't to make every project production-ready.

The goal is to take an idea and ask:

> **"Can I build this myself?"**

Then figure it out.

Some projects might be tiny.
Some might be ridiculous.
Some might break spectacularly.

But each one should teach me something new.

##  No Vibe Coding

One rule:

### **I want to understand the code I write.**

AI can explain things.
AI can help me debug.
AI can point me in the right direction.

But this repo is about **learning the logic**, not generating code blindly and calling it a project.

The objective is:

```text
Idea
 ↓
Think
 ↓

 ↓

```
